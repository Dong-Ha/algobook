문서의 기본 예제입니다. 실험에서 변경한 입력을 반영한 인쇄 결과는 아닙니다.

01 / BOUNDARY SEARCH

최소 용량은 어디서 가능해질까?

작업 순서를 유지하고 작업을 쪼개지 않습니다. 양의 작업량을 D일 이내에 처리하는 최소 하루 용량 C를 찾습니다.

불변식 · 최소 가능한 용량은 [lo, hi] 안에 있습니다.용량을 늘려도 필요한 날짜 수는 늘지 않습니다. 가능한 mid는 답 후보로 남기고, 불가능한 mid 이하는 버립니다.

02 / FRONTIER & PATH

도착하기 전, 큐에는 무엇이 남을까?

상하좌우 이동 비용은 모두 1입니다. 왼쪽 위 S에서 오른쪽 아래 T까지 최소 이동 횟수와 경로 하나를 찾습니다.

불변식 · 처음 큐에 넣을 때 거리와 부모를 기록합니다.큐에는 먼저 발견한 칸부터 들어 있습니다. 같은 칸을 다시 넣지 않으며, 방문 거리와 최종 경로는 서로 다른 정보입니다.

03 / CANDIDATES & RECONSTRUCTION

tails를 그대로 답으로 쓰면 왜 틀릴까?

엄격 증가 부분수열을 찾습니다. 길이별 최소 끝값 후보와 실제 원본 인덱스의 연결을 구분하세요.

불변식 · tails[k]는 길이 k+1인 후보의 최소 끝값입니다.교체는 더 유리한 끝값을 남깁니다. 실제 수열은 각 원소를 처리할 때 기록한 parent 인덱스를 따라 복원합니다.
